# storefront

Checkout for the shop. All money is in cents.

- `src/catalog` – products
- `src/cart` – cart totals and weight
- `src/shipping` – shipping rates
- `src/coupons` – coupon list, checks and discounts
- `src/checkout.js` – prices a cart

Run the tests with `node --test --test-reporter=tap test/*.test.js`.
